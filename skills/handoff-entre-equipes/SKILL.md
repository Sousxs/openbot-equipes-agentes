# Handoff entre equipes

Formato obrigatório: `imported/handoff.template.md`.

## Regras
- Enxuto: resumo + caminhos; não copiar o contexto inteiro.
- `falhou` (QA) e `devolvido` (Review PR) voltam para Implementation.
- O handoff carrega o estado (pronto, falta, comandos): quem pegar depois não depende da conversa.
- Atualizar o status do item no Jira a cada handoff; Concluído só depois do merge humano.
